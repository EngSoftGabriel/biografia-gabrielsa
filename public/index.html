Engenharia de software e dados

Transformo problemas reais em soluções digitais eficientes.

Sou Gabriel Silva de Almeida, desenvolvedor de software. Atuo no desenvolvimento web, automação e análise de dados para criar aplicações organizadas, escaláveis e alinhadas aos objetivos de cada projeto.

Experiência que combina código e visão de negócio

Bacharel em Engenharia de Software e pós-graduando em Ciência de Dados, atuo como freelancer desde 2022. Desenvolvo aplicações com JavaScript, Python e SQL, sempre com foco em resolver o problema certo, organizar os dados e entregar uma experiência confiável para quem usa a solução.

Minha experiência inclui automação de relatórios, integração de dados de múltiplas fontes, APIs REST, bancos MySQL e SQLite, autenticação com JWT, Git e integração contínua. Também participei da construção de uma plataforma de RH e de projetos voluntários, o que fortaleceu minha colaboração, organização e responsabilidade com cada entrega.
