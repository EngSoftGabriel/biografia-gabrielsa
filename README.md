# Biografia do Gabriel

Página pessoal criada para apresentar um pouco sobre Gabriel, sua atuação como desenvolvedor web e seus canais de contato.

## Sobre o projeto

Este projeto é uma página web estática desenvolvida com:

- HTML5
- CSS3
- JavaScript
- Node.js, previsto para o servidor local

A página possui uma navegação simples com as seções **Início**, **Sobre** e **Contato**.

## Demonstração

O projeto está disponível em:

[biografia-gabrielsa](https://github.com/EngSoftGabriel/biografia-gabrielsa)

## Como executar

### Pré-requisitos

- [Node.js](https://nodejs.org/) instalado
- npm instalado junto com o Node.js

### Execução local

Como os arquivos da interface ficam dentro da pasta `public`, a forma mais simples de visualizar o projeto é abrir diretamente o arquivo `public/index.html` no navegador.

Para servir a página por HTTP, instale e execute um servidor estático de desenvolvimento:

```bash
npx serve public
```

Em seguida, acesse o endereço exibido no terminal, normalmente `http://localhost:3000`.
